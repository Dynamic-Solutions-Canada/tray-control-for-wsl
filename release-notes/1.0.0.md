- First release: see which WSL distros are running from the tray icon, and start or stop each one with a click.
- Distros that use systemd stop cleanly, and Stop asks for a second click so a stray click can't end your work.
- Shut down WSL stops every distro cleanly, then frees WSL's memory.
- A details window shows each distro's WSL version (1 or 2), location and, for WSL 2, disk size, with shortcuts to a terminal or its files.
- Available in English, Spanish, French, German, Simplified Chinese, Brazilian Portuguese and Japanese.
